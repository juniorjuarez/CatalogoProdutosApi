# 🚀 Prompt Rápido - Metodologia Didática

## Versão Pronta para Copiar e Colar

```
Transforme esta documentação técnica em um guia memorável usando metodologia de aprendizado ativo.

Para CADA conceito, siga esta estrutura obrigatória:

1. 🎭 Para que serve? (Analogia Prática)
   - Use analogia do mundo real (carro, restaurante, biblioteca, etc.)

2. ❌ O Problema (Refinamento Progressivo)
   - MOSTRE código ruim primeiro (sem o conceito)
   - Liste problemas com 🔴
   - Explique o "caos" antes da solução

3. ✅ A Solução Recomendada
   - MOSTRE código bom (com o conceito)
   - Liste benefícios com ✅
   - Conecte com a analogia

4. 🔄 Fluxo Lógico: Como Funciona
   - Diagrama de texto com setas (→)
   - Mostre passo a passo como os dados viajam

5. 📝 Receita de Bolo (Como Implementar)
   - Passos numerados claros
   - Código de exemplo em cada passo
   - Use "💡 Lembre-se:" para dicas
   - Conecte com conhecimentos básicos (POO, interfaces, etc.)

6. 🎯 Conceitos Importantes
   - Pontos-chave destacados
   - Exemplos práticos do projeto

7. 📚 Documentação Oficial
   - Links para aprofundamento

REGRAS:
- Tom conversacional (como explicando para um colega)
- Evite jargão técnico excessivo
- Sempre problema ANTES da solução
- Use emojis estrategicamente
- Conecte conceitos avançados com básicos
- Use "Você já conhece isso de..." para criar pontes

NÃO FAÇA:
- ❌ Começar direto com solução técnica
- ❌ Assumir conhecimento avançado sem explicar básico
- ❌ Usar apenas listas de "O que é"
- ❌ Pular o problema antes da solução
```
